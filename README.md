# 상속세 간단 계산기

블로그 방문자가 재산 규모만 입력하면 **상속세가 나오는 구간인지** 바로 확인하고,
상황에 따라 **상담이 필요한 이유**를 안내받을 수 있는 정적 웹 계산기입니다.

홈택스 간편계산 방식을 참고하되, 세무 지식이 없는 사람도 채울 수 있도록 항목을 정리했습니다.

- **독립 페이지**: `index.html`
- **블로그 삽입용**: `index.html?embed=1` (헤더 여백이 줄고 배경이 투명해집니다)
- **삽입 예시**: `embed-demo.html` — 블로그 글 안에 넣었을 때 어떻게 보이는지 확인용

---

## 1. 배포 후 가장 먼저 할 일

**`assets/js/config.js` 파일의 연락처를 실제 정보로 바꿔주세요.**
이걸 비워두면 상담 버튼이 아예 표시되지 않아, 계산만 되고 상담으로 이어지지 않습니다.

```js
export const CONTACT = {
  phone: '02-1234-5678',                       // 전화 상담 버튼
  kakaoUrl: 'https://pf.kakao.com/_abcdefg',   // 카카오톡 채널
  email: 'tax@example.com',                    // 이메일 문의
  formUrl: '',                                 // 네이버폼·구글폼 주소가 있다면
  hours: '평일 09:00 ~ 18:00',
};

export const SITE = {
  officeName: '○○세무회계사무소',              // 화면 맨 아래 표시됩니다
};
```

값을 비워둔 항목은 버튼이 나타나지 않습니다. 필요한 것만 채우면 됩니다.
파일을 수정하고 `main` 브랜치에 push하면 몇 분 안에 사이트에 반영됩니다.

## 2. 블로그에 붙이는 방법

### 방법 A — 본문에 그대로 녹여 넣기 (권장)

계산기 내용에 맞춰 높이가 자동으로 늘어나므로 스크롤이 두 번 생기지 않습니다.
네이버·티스토리 블로그의 **HTML 편집** 모드에서 아래 코드를 붙여넣으세요.

```html
<iframe
  id="inheritance-calc"
  src="https://wldms2589-star.github.io/inheritance-tax-calculator/index.html?embed=1"
  title="상속세 간단 계산기"
  style="width:100%; height:1200px; border:1px solid #e0e0e0; border-radius:10px;"
  loading="lazy"></iframe>
<script>
window.addEventListener('message', function (e) {
  if (e.data && e.data.type === 'inheritance-calculator:height') {
    var f = document.getElementById('inheritance-calc');
    var h = e.data.height + 'px';
    if (f && f.style.height !== h) f.style.height = h;
  }
});
</script>
```

### 방법 B — 높이를 고정하고 안에서 스크롤

블로그 글이 너무 길어지는 게 부담스러우면 `<script>` 없이 iframe만 넣고 높이를 고정하세요.
계산기 안쪽에 스크롤이 생깁니다.

```html
<iframe
  src="https://wldms2589-star.github.io/inheritance-tax-calculator/index.html?embed=1"
  title="상속세 간단 계산기"
  style="width:100%; height:800px; border:1px solid #e0e0e0; border-radius:10px;"
  loading="lazy"></iframe>
```

### 방법 C — 링크만 걸기

일부 블로그 서비스는 `<script>`를 지웁니다. 그럴 때는 링크로 연결하세요.

```html
<a href="https://wldms2589-star.github.io/inheritance-tax-calculator/">
  상속세 얼마나 나오는지 계산해보기 →
</a>
```

## 3. 무엇을 계산하나요

### 반영하는 항목

| 단계 | 항목 |
|---|---|
| 상속재산 | 부동산, 금융재산, 그 밖의 재산, 간주상속재산, 추정상속재산 |
| 차감 | 공과금, 장례비용(최소 500만·최대 1,000만 + 봉안시설 500만), 채무, 비과세 |
| 가산 | 10년 이내 사전증여재산 |
| 공제 | 기초공제 2억 + 인적공제 vs 일괄공제 5억 중 큰 금액 |
| | 배우자 상속공제 (최소 5억 ~ 최대 30억, 법정상속분 한도 적용) |
| | 금융재산 상속공제 (최대 2억) |
| | 동거주택 상속공제 (최대 6억) |
| | 재해손실공제, 감정평가수수료 |
| 세율 | 과세표준 구간별 10% ~ 50% (누진공제 적용) |
| 할증·공제 | 세대생략 할증 30%(미성년 20억 초과 40%), 증여세액공제, 외국납부세액공제, 신고세액공제 3% |

배우자 단독상속(자녀 등 다른 상속인이 없는 경우)에는 일괄공제를 적용하지 않으며,
상속공제 합계가 과세가액을 넘지 못하도록 공제 적용 한도도 반영합니다.

### 반영하지 않는 항목

아래는 요건이 복잡해 계산기에 넣지 않았습니다. 해당하면 화면에서 별도로 안내합니다.

- 가업상속공제 · 영농상속공제
- 단기재상속에 대한 세액공제
- 비상장주식 · 특수한 재산의 평가
- 상속인이 아닌 사람에 대한 유증, 상속포기에 따른 공제 한도 조정

## 4. 상담으로 이어지는 안내

단순히 세액만 보여주지 않고, 입력 내용과 상황 체크 결과를 조합해 안내 문구를 골라 보여줍니다.
우선순위가 높은 것부터 표시됩니다.

가장 중요한 것은 **"부동산을 앞으로 팔 계획이 있는가"** 문항입니다.

> 상속세가 0원이어도, 신고를 하지 않으면 나중에 그 부동산을 팔 때
> 낮은 공시가격이 취득가액이 되어 양도소득세가 크게 늘어납니다.
> 감정평가를 받아 시가로 신고해두면 상속세는 그대로 0원이면서 취득가액만 높일 수 있습니다.

그 밖에 다음 상황을 감지해 안내합니다.

- 신고기한 임박 / 경과 (상속개시일 입력 시 자동 계산)
- 과세 경계 구간 — 재산이 조금만 더 확인되면 과세로 바뀌는 상태
- 세율 구간 경계에 걸친 경우
- 배우자 상속공제 분할 설계, 배우자 단독상속
- 사망 전 인출·처분(추정상속재산) 위험
- 가업·영농 상속, 비상장주식, 세대생략 상속
- 납부재원 부족 → 연부연납 · 물납 검토
- 놓치기 쉬운 금융재산·동거주택 공제

안내 문구를 고치거나 추가하려면 `assets/js/advice.js`를 수정하세요.

## 5. 세법이 바뀌면

세율과 공제 한도는 **`assets/js/tax-rules.js` 한 파일에** 모여 있습니다.
계산 로직을 건드리지 않고 숫자만 바꾸면 됩니다.

```js
// 예: 자녀공제를 1인당 5천만원에서 5억원으로 바꾸는 경우
personal: {
  perChild: 5 * 억,   // 5000 * 만 → 5 * 억
  ...
}
```

바꾼 뒤에는 반드시 테스트를 돌려 계산이 깨지지 않았는지 확인하세요.
`npm test`는 배포 전에 GitHub Actions에서도 자동으로 실행됩니다.

## 6. 로컬에서 확인하기

ES 모듈을 사용하므로 `index.html`을 파일로 직접 열면 동작하지 않습니다. 반드시 서버로 띄우세요.

```bash
npm run serve     # http://localhost:4173
npm test          # 계산 로직 검증 (55개)
```

Node 18 이상이면 별도 설치 없이 그대로 실행됩니다. 외부 라이브러리를 쓰지 않습니다.

## 7. 파일 구조

```
├── index.html              계산기 본체
├── embed-demo.html         블로그 삽입 미리보기
├── assets/
│   ├── css/style.css       스타일 (다크 모드·인쇄 대응)
│   └── js/
│       ├── config.js       ★ 연락처·사무소명 (배포 시 수정)
│       ├── tax-rules.js    ★ 세율·공제 한도 (법 개정 시 수정)
│       ├── tax.js          계산 엔진 (순수 함수)
│       ├── advice.js       상담 안내 문구 선택 로직
│       └── app.js          화면 제어
├── test/                   계산·안내 로직 테스트
├── scripts/serve.mjs       로컬 확인용 서버
└── .github/workflows/      테스트 후 자동 배포
```

`tax.js`와 `advice.js`는 화면에 의존하지 않아 Node에서 그대로 테스트할 수 있습니다.

## 8. 면책

이 계산기는 현행 「상속세 및 증여세법」에 따라 대략적인 세액을 추정하는 **참고용 도구**입니다.
실제 세액은 재산의 평가 방법, 상속인 구성, 사전증여 내역, 가업상속공제 등 개별 사정에 따라
달라집니다. 계산 결과에 대해 법적 책임을 지지 않으며, 정확한 세액은 세무 전문가와 상담하시기 바랍니다.

화면 하단의 면책 문구는 `assets/js/config.js`의 `DISCLAIMER`에서 수정할 수 있습니다.
분쟁 예방을 위해 문구를 삭제하지 않는 것을 권합니다.
